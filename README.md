# 🧾 Radar de Gastos Hormiga

Aplicación web para detectar y controlar los **gastos hormiga**: esos pequeños gastos diarios (café, antojos, taxis) que sumados se comen el presupuesto sin que lo notes.

## ✨ Funcionalidades

- 🐜 **Gastos hormiga** — Registro rápido con descripción, monto, categoría y **detonante emocional** (😫 Cansancio, ⌛ Falta de tiempo, 🎉 Ocio social, 🍫 Antojo puro) para identificar *por qué* compras.
- 💰 **Ingresos** — Registro de entradas de dinero (quincena, freelance, etc.).
- 📌 **Gastos fijos** — Control separado de arriendo, servicios, suscripciones y cuotas.
- 📊 **Dashboard interactivo** — Tarjetas clicables de Total ingresos, Gastos hormiga, Gastos fijos y **Balance neto** (verde si es positivo, rojo si gastas más de lo que ingresas).
- 📅 **Filtros por fecha** — Hoy, últimos 7 días, este mes, todo, o rango personalizado.
- 🥧 **Desglose por categorías** — Barras de porcentaje clicables que filtran el historial por categoría.
- 🔍 **Secciones plegables** — Acordeones para ver solo lo que necesitas.
- 📈 **Exportación a Excel** — Descarga tus registros en CSV compatible con Excel.
- 💾 **Persistencia local** — Todo se guarda en `localStorage`, sin necesidad de servidor ni cuentas.

## 🚀 Cómo usar

1. Descarga `radar-gastos-hormiga.html`
2. Ábrelo con doble clic en cualquier navegador
3. ¡Listo! No requiere instalación ni internet (solo CDN de Tailwind)

## 🛠️ Tecnología

- **HTML5** — Un solo archivo autocontenido
- **Tailwind CSS** (CDN) — Estilos minimalistas mobile-first
- **JavaScript vanilla** — Sin dependencias ni frameworks
- **localStorage** — Persistencia de datos en el navegador

## 🎨 Diseño

Paleta cálida y elegante con tonos nude, crema y acentos purple/retro. Interfaz responsiva (mobile-first) pensada para uso diario desde el celular.
